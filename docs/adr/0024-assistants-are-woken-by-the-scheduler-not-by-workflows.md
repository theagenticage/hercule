# Assistants are woken by the scheduler, not by workflows

Anything that wakes an assistant at a *time* rather than on an *event* - the standing heartbeat and one-shot reminders - is a core-owned **Scheduled Wake**: the controller's single Scheduler (the same component that fires `cron.tick` for workflow triggers) enqueues a prompt as Queued Input on the assistant's conversation, starting or resuming its session. A wake never enters the event pipeline, creates no run, and needs no workspace. The alternative was to route assistant scheduling through the workflow system: a stored workflow with a cron trigger and one workspace-less agent step running the assistant's agent. That route is not blocked by workspaces (workspace policy `none` already exists) but it makes the woken assistant a stranger to itself: an agent step runs a fresh session inside a run, with no conversation, no injected memory (delegated sessions see none by design), none of the conversation's subscriptions, and no way to speak except `notification.create`; it also needs a one-shot trigger, `workflow.write` on the assistant profile, and a new kind of assistant session with its own memory and taint rules, and it puts a run in the history for every hourly heartbeat. A wake lets the assistant act *as itself*, in the conversation where the user talks, with memory and context; everything it can do on a wake it does by delegation, so "do X later" covers any X it can do now. The costs accepted: schedules now live in two places (workflow triggers, and an assistant's heartbeat and reminders), a wake is a prompt rather than a frozen plan, and "schedule a workflow for later" is a reminder that submits the workflow at wake rather than a direct trigger. That bridge is the thing dogfooding must judge; the additive fixes if it proves clumsy are a one-shot `at` trigger on workflows and `workflow.write` for assistants. Deterministic scheduled work stays a workflow with a cron trigger; a missed cron tick is skipped, a missed reminder fires late, because one is a cadence and the other a promise.
