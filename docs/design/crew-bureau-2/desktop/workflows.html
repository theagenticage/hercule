Ship release

Prepares a release in parallel, opens the release PR, and announces it once the PR is merged.

When on, its triggers start runs. Runs already going are not touched.

  • github.issue.labeled
  • Fridays at 14:00 · next Fri 14:00
  • 6 agents · 2 actions · 1 signal

StatusStarted byTookStarted
TriggerDoesFires onState

version string Optional 
name: Ship release
description: Prepares a release in parallel, opens the release PR, and announces it once the PR is merged.
inputs:
  - name: version
    schema:
      type: string
    required: false
triggers:
  - id: release_issue
    kind: start
    on:
      kind: github.issue.labeled
      connectionId: any
      filter: event.payload.label.name == "release"
    inputs:
      version: event.payload.issue.title
  - id: release_train
    kind: start
    on:
      schedule: 0 14 * * 5
  - id: pr_merged
    kind: signal
    on:
      kind: github.pr.merged
      connectionId: any
    correlation:
      event: event.payload.number
      run: steps.open_pr.output.number
steps:
  - id: changelog
    kind: agent
    agent: 01a0ec64-6e80-7000-8000-a00000000001
    prompt: Write the changelog for {{ inputs.version }} from the merged pull requests.
  - id: security
    kind: agent
    agent: 01a0ec64-6e80-7000-8000-a00000000002
    prompt: Audit the dependencies and fix what you can.
  - id: test
    kind: agent
    agent: 01a0ec64-6e80-7000-8000-a00000000003
    prompt: Run the full test suite and the end-to-end tests.
  - id: review
    kind: agent
    agent: 01a0ec64-6e80-7000-8000-a00000000004
    prompt: Review the release diff. Answer approved or changes.
    outputSchema:
      type: object
      properties:
        verdict:
          enum: [approved, changes]
      required: [verdict]
    entry: true
  - id: fix
    kind: agent
    agent: 01a0ec64-6e80-7000-8000-a00000000005
    prompt: Make the changes the review asked for.
  - id: open_pr
    kind: action
    action: github/pr.create
    params:
      connection: any
      title: Release {{ inputs.version }}
      head: release/{{ inputs.version }}
      base: main
    join: all
  - id: announce
    kind: agent
    agent: 01a0ec64-6e80-7000-8000-a00000000001
    prompt: Write the release announcement from the changelog.
  - id: notify
    kind: action
    action: notification.create
    params:
      title: Released {{ inputs.version }}
    terminal: true
edges:
  - from: changelog
    to: open_pr
  - from: security
    to: open_pr
  - from: test
    to: open_pr
  - from: review
    to: open_pr
    condition: steps.review.output.verdict == "approved"
  - from: review
    to: fix
    condition: steps.review.output.verdict == "changes"
  - from: fix
    to: review
    maxTraversals: 3
  - from: pr_merged
    to: announce
  - from: announce
    to: notify
