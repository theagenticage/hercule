# Playbook (starting text)

Draft for slice P of the Triage map (#1176, #1182). The Playbook is the user's own text: which work triage may start by itself, and which it only proposes. Hercule ships this starting text once and never overwrites it. Triage may offer a new line; only the user adds it.

Everything below the line is the Playbook as a new triage gets it.

---

## Start yourself

Nothing.

## Propose only

Everything.

## Set aside

Only what Hercule's instructions already allow: a leftover ask on a thing that is finished at its source, and a thing a Thread looked at and found nothing to do about.

## Never

Merge anything.

---

## Lines a user might add later

These are examples, written for the invented Northwind Market world. They are not part of the starting text.

- Start yourself: errors in the catalog service with a clear stack trace. Collect what you find on the Task, then ask me.
- Start yourself: a failed check on a pull request I opened in `webshop`, when the same check fails on other pull requests too.
- Propose only: anything in `payments-api`, and anything a customer reported.
- Hand to "Review PR": review requests in `webshop` from my own team.
- Set aside: browser-extension errors with no affected users.
- Set aside: errors that only happen on staging, unless they started after a merge of mine.
- Never start work on a draft pull request somebody else opened.
- For tickets, start a Thread. Do not hand them to "Ticket to PR": its runs fail too often.
