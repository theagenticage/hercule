# hydra

An agent orchestration platform: always-on controller, registerable runners, event-triggered workflows, assistants bound to communication channels, and a plugin architecture throughout. Successor to agentick, built from scratch.

**Status: planning.** The way to the v1 spec is being charted on the [wayfinder map](https://github.com/rogierpennink/hydra/issues/1) - decisions are worked as its child issues.

Research findings land on `research/*` branches under `research/`.
