# hydra

An agent orchestration platform: always-on controller, registerable runners, event-triggered workflows, assistants bound to communication channels, and a plugin architecture throughout. Successor to agentick, built from scratch.

**Status: spec assembled, implementation not started.** The v1 spec lives in [docs/spec/](docs/spec/README.md); the decisions behind it were worked as child issues of the [wayfinder map](https://github.com/rogierpennink/hydra/issues/1), and the questions assembly left open are indexed in [docs/spec/16-open-items.md](docs/spec/16-open-items.md), each tied to a follow-up ticket.

Research findings land on `research/*` branches under `research/`.
