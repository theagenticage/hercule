The status icons in status-icons.ts are taken from GitHub's Octicons: each is
the `d` of the paths in the file named below, copied unchanged.

Source:  https://github.com/primer/octicons
Package: @primer/octicons 19.15.0

  git-pull-request-16.svg        -> PULL_REQUEST_OPEN_ICON
  git-pull-request-draft-16.svg  -> PULL_REQUEST_DRAFT_ICON
  git-merge-16.svg               -> PULL_REQUEST_MERGED_ICON
  git-pull-request-closed-16.svg -> PULL_REQUEST_CLOSED_ICON
  issue-opened-16.svg            -> ISSUE_OPEN_ICON
  issue-closed-16.svg            -> ISSUE_CLOSED_ICON

Copied on 2026-11-10. Nothing is fetched from GitHub at build time or at
runtime.
