Metro, iteration 1

Metro Wayfinding

The map where it explains, plain signs everywhere else.

Metro keeps its brand: enamel-sign letters, the H logo, and one colored line per Connection. What changes is where the map appears. It is drawn where work moves, and only there: Intake's flow from sources to Triage to proposals, a Proposal's "made from" glyph, the route under a Thread, the check-in timetable, and quietly on the office floor. Everything else uses plain signs: threads first in the sidebar, one outline icon set, six state marks, no monospace outside code. Glass stays on floating layers, at 35%.

Why this one

Pick Wayfinding if you liked Metro's identity but not living inside a diagram. Against the original, the map now appears only where work moves: Intake's flow, a Proposal's made-from glyph, the route under a Thread, the check-in timetable. Everything else is ordinary, readable software: a threads-first sidebar, one icon set, six marks, no mono.

Against Concourse, Wayfinding is solid first: glass at 35% and only on floating layers, and the flow is a place you visit rather than a strip on every screen.

What it trades away. Less spectacle, so the brand leans on letters, color and the logo more than on motion. The office is quieter: grey lines until you point at a desk or switch Event flow on. And at the default level the glass is barely noticeable. That is the point, but it may read as timid.

--bg --bg Window ground: sidebar and titlebar. Warm neutral; no dark theme is blue.
--surface --surface The main canvas, lighter than the ground, so content leads.

--ink --ink, --trunk Text, and Hercule's own work where lines meet. --trunk aliases it so a theme may part them later.
--muted --muted Darker in light, lighter in dark: 4.5:1 at 12.5px on every surface.
--faint --faint Now readable (54% and 65%). Today's 66% and 50% fail contrast for text.
--line --line Hairlines, and the links of a route strip. A Connection's line is its hue, never --line.
--line-soft --line-soft Row separators. Unchanged in role.
--attn --attn, --attn-soft Waiting on you: the ring and the word. Never a button fill.
--fail --fail Failed, urgent, and the text of a button that destroys something. Never on a line.
--live --live Green, not blue-grey: working reads as go. Always with the breathing mark.
--ok --ok Done words. The done mark itself is ink.
--project-* --zone-* Project dots go. A project's color is a rug in the office; hue belongs to Connections.
new --ln-*, --casing One hue per Connection type, tuned per theme. --casing is the gap drawn where lines cross.
new --glass-level One number from 0 to 1, 0.35 by default. --glass, --glass-thin, the blur, the saturation and the light edge all follow from it.

What this design asks the spec to change

Everything else is presentation over today's operations.
A per-Proposal addressA link from Slack or email opens one Proposal as a page. The URL space has /intake but no address for one Proposal; add /intake/<proposal id>.spec 14 · URL space
Counts per Connection and outcomeThe flow diagram needs, since you last checked, event counts per Connection and per triage outcome. Today's Intake brief has the outcome totals only.spec 10 · Intake · spec 11 · a read
A color per Connection typeConnection types are plugin-defined, so a type needs a color slot: a palette index in the plugin manifest, or a client-core fallback. Two Gmail Connections share the Gmail color and differ by name.spec 05 · manifest · spec 08 · Connection
One filled answer per questionThe design language asks for quiet text-only answers everywhere. Wayfinding fills the one suggested answer, keeps the others neutral or quiet, and uses red text only for destroying something.spec 14 · Design language · docs/design-language.md
Mono only inside codeThe design language sets ids, refs, ages and counts in mono. Wayfinding sets them in Overpass with tabular numerals, and keeps Overpass Mono for code.spec 14 · Design language
Five themes and a glass levelThe theme row offers Light, Dark and System. Wayfinding offers five themes, with Light and Dark as aliases, and a Glass level. Both stay per browser, like the theme today.spec 14 · Sidebar foot, the theme row
The tab as a signalPin the tab title as "(n) screen · Hercule", n being decisions waiting, and a favicon that gains a ring while n is above zero.spec 14 · App shell
Mobile opens on IntakeHome is Sessions on desktop and web, as pinned. On a phone the first tab is Intake, because that is where decisions get made on the go.spec 14 · Home is Sessions
