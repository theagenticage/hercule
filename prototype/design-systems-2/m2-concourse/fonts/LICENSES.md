# Fonts

Every font is self-hosted from this folder. The pages make no font requests to any other host.

| File | Family | Axes | Role in Metro Concourse | License | Source |
|---|---|---|---|---|---|
| `overpass-var.woff2` | Overpass | wght 100-900, latin subset | Signs: titles, navigation, labels, buttons, counts, the departures board | SIL Open Font License 1.1 | Google Fonts via Fontsource (`overpass`, v19) |
| `inter-latin-wght.woff2` | Inter | wght 100-900, latin subset | Sentences: transcript prose, descriptions, notes | SIL Open Font License 1.1 | Fontsource (`inter`), copied from round 1's Concierge |
| `overpass-mono-var.woff2` | Overpass Mono | wght 300-700, latin subset | Code, commands, diffs and the composer lip's branch only | SIL Open Font License 1.1 | Google Fonts via Fontsource (`overpass-mono`, v21) |

Overpass is Copyright 2016 Red Hat, Inc., designed by Delve Withrington with Dave Bailey and Thomas
Jockin. It is an open typeface inspired by Highway Gothic, the lettering of North American road
signs: it was drawn to be read at a glance, at a distance, in motion. That is why the signs use it.

Inter is Copyright 2016 The Inter Project Authors, designed by Rasmus Andersson. It was drawn for
text on screens at small sizes, which is why the sentences use it.
