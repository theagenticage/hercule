Checkout fails for EU cards that need 3-D Secure since deploy #1289. Find the cause and fix it. Add a test that reproduces it first.
09:02

Found it. Since Stripe SDK v14, confirmPayment returns status: 'requires_action' for cards that need 3-D Secure. handlePaymentResult in src/checkout/payment.ts only handles succeeded and treats everything else as a failure, so we show "Card declined" instead of opening the 3-D Secure modal.

if (result.status === "requires_action") { return openThreeDSModal(result.clientSecret); }

I wrote a failing test first, then the fix. The test pays with an EU card that asks for 3-D Secure and expects the modal:

it("opens 3-D Secure when the card requires action", async () => { mockConfirm({ status: "requires_action", clientSecret: "pi_3Q_secret" }); await pay(euCard); expect(openThreeDSModal).toHaveBeenCalledWith("pi_3Q_secret"); });
