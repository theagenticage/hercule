# Fonts used by Aurora

Both families are self-hosted woff2 files, downloaded once from fontsource (jsDelivr). Pages make
no font requests outside this folder.

| File | Family | Axes | Licence |
|---|---|---|---|
| `figtree-latin-wght.woff2` | Figtree, by Erik Kennedy | wght 300-900 | SIL Open Font License 1.1 |
| `figtree-latin-ext-wght.woff2` | Figtree (Latin Extended subset) | wght 300-900 | SIL Open Font License 1.1 |
| `jetbrains-mono-latin-wght.woff2` | JetBrains Mono, by JetBrains | wght 100-800 | SIL Open Font License 1.1 |

Licence text: https://openfontlicense.org/open-font-license-official-text/
