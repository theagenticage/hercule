Spectrum

Color is context. The hue tells you where; the shape tells you what.

Hercule design system · 09

Every project in Hercule gets a hue: webshop is tangerine, payments-api violet, ops green. Wherever you are, the window takes that hue, so you know which project you are in before you read a word. Every live session is a segment in the band at the foot of the sidebar, colored by its project and lit by its state: one look shows where the swarm is spending itself. Things that span projects wear the spectrum. State never borrows a color. It is a shape, and "needs you" is solid ink.

01 · Why this one

Sort by where
the work lives.

Rogier's work is divided by project, and so is the swarm: every session runs in a workspace of one project. Today the project is a 6px dot and a word, so every screen must be read before it can be placed.

Spectrum makes the project the first thing you see. The window, the row, the answer button and the band segment all wear its hue, so you sort in peripheral vision, before reading. The other directions organize by decision, source or state; this one organizes by place.

What it trades away

No traffic lights. State is a mark and a brightness; needs you is ink. A red-means-bad habit goes.
Hues run out. Past eight projects a hue repeats, with a stripe.

05 · The office

The band,
unfolded.

The office is not a second system. It draws the band's 23 segments as desks, in the same order, the same hues and the same flags, with room to breathe.

1A zone is a project.Its rug is the project's hue; its name is on the wall behind it.
2A desk is a session.The screen is lit when it works, dim when idle, hatched when paused.
3A flag is a question.Ink, above the desk, with the thread's title. The same flag as on the band.
4The band runs along the walls.Each project's segments sit on the wall behind its zone.
5The lounge is for assistants.They belong to no project, so their rug is the spectrum.
6Runners are cabinets.A light per session they host; a full one says so.

Fold the office flat along its walls and you get the band. The sidebar carries it everywhere; the office is where you go to see the same thing large. Every desk opens its session.

07 · Adopting it

A token swap,
then five changes.

Today's names keep their meaning where it holds, so most of packages/ui moves by swapping one stylesheet. The four semantic hues are the real change.

1

Swap the tokens

Replace Midnight with Spectrum's tokens.

  • packages/ui/src/styles.css: the five themes; light and dark stay as aliases, so the theme row keeps working.
  • packages/ui/src/fonts: add Instrument Sans and Martian Mono, self-hosted.
2

Give every project a hue

A stored hue on the project, and one component that draws it.

  • A hue field on the project; a client-core function picks the first free of eight.
  • A <Swatch> in packages/ui replaces the 6px project dot.
3

Tint by space

One attribute on the shell root drives every tinted surface.

  • apps/web/src/shell/shell.tsx: set data-space from the route.
  • apps/web/src/shell/sidebar.tsx: the space switcher at the foot; the two faces become spaces.
4

Build the band

The pulse becomes the band, fed by the live session list.

  • Replace apps/web/src/shell/pulse.tsx with a <Band> in packages/ui.
  • Merging into runs past about 60 sessions is a client-core function with its own test.
5

Redraw marks, fill the first answer

State by shape and luminance; the suggested answer in the project hue.

  • packages/ui/src/marks/marks.tsx: marks in currentColor, needs you as the ink disc.
  • packages/ui/src/primitives/button.tsx: a go variant painted in --p.
08 · What it asks of the spec

Six changes,
two contradictions.

Spectrum needs the project to own a hue, and it undoes two rules of today's design language. Each is listed with where it lands.

1 · A project gets a hue

Eight hues; a new project takes the first free one; you can change it. Past eight, hues repeat with a stripe.

Spec 02, Project · spec 14, New project dialog

2 · Semantic hues go contradicts

Amber, clay, petrol and sage are removed. State is a mark and a brightness; needs you is ink. Project swatches appear wherever a project does, not only on group headers.

Spec 14, Design language · docs/design-language.md

3 · The pulse becomes the band

The sidebar foot shows a segment per live session. On the web it is a strip on the top edge; on the phone, the tab bar's top edge.

Spec 14, App shell, sidebar foot

4 · Sidebar faces become spaces

Threads and Hercule become All projects (orchestration, projects, assistants) and one space per project (threads by workspace, runs, assistants). The switcher shows a ? per project that needs you.

Spec 14, App shell

5 · The first answer is filled contradicts

The suggested answer is a filled button in the project hue, keyed 1. The other answers stay quiet. Today's rule says decisions are text-only ghost buttons on monitoring surfaces.

Spec 14, Design language

6 · The web shell is a rail and a list

A 64px rail of spaces and places beside the space's list, and a 740px thread column instead of 800, so prose keeps to about 85 characters a line.

Spec 14, App shell and thread layout

Beyond v1

The phone screens, the lock screen and native notifications assume a mobile app and push, which v1 does not have (no Web Push). They reuse the Notification's bound actions, so the answers are the same ones the web app offers (ADR 0012).
