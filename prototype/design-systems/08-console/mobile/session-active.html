Found it. Since Stripe SDK v14, confirmPayment returns requires_action for cards that need 3-D Secure. handlePaymentResult treats that as a failure, so we show "Card declined" instead of opening the 3-D Secure modal.

src/checkout/payment.ts
if (result.status === "requires_action") {
  return openThreeDSModal(result.clientSecret);
}
