# Fonts

Both families are self-hosted woff2 files (Latin subset, variable weight axis), downloaded once from
Fontsource. No page requests a font from the network.

| File | Family | Designer | Licence |
|---|---|---|---|
| `outfit-var.woff2` | Outfit (100-900) | Rodrigo Fuenzalida, On Brand Investments Pty Ltd | SIL Open Font License 1.1 |
| `geist-mono-var.woff2` | Geist Mono (100-900) | Vercel, Basement Studio | SIL Open Font License 1.1 |

The SIL Open Font License 1.1 allows use, bundling and redistribution, including in commercial
software, as long as the fonts are not sold on their own and the licence travels with them:
https://openfontlicense.org/open-font-license-official-text/
