# Fonts used by Crew Bureau

Every family is a self-hosted woff2 file downloaded once from fontsource's CDN. Nothing is fetched at runtime.

| Family | Files | Used for | Axes used | Licence |
|---|---|---|---|---|
| Bricolage Grotesque (Mathieu Triay) | `bricolage-grotesque-latin-standard-normal.woff2`, `bricolage-grotesque-latin-ext-standard-normal.woff2` | All interface text | wght 200-800, opsz 12-96, wdth 75-100 | SIL Open Font License 1.1 |
| Limelight (Nicole Fally, Sorkin Type) | `limelight-latin-400-normal.woff2` | The wordmark, the logo lettering and a few large numerals. Never body text | none (one weight) | SIL Open Font License 1.1 |
| Recursive (Arrow Type) | `recursive-latin-full-normal.woff2` | Code blocks, diffs, commands and branch names only | MONO 1, CASL 0.5, wght 300-1000 | SIL Open Font License 1.1 |
